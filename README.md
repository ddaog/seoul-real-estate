# seoul-real-estate

## 🏙️ Seoul Land Lord: Reigns Edition

대한민국 서울의 뜨거운 부동산 시장을 풍자하는 카드 스와이프 서바이벌 게임입니다.

## 🎮 게임 컨셉
유명한 게임 'Reigns'의 메커니즘을 차용하여, 사용자는 서울 부동산 시장의 보이지 않는 손이 되어 다양한 선택을 내립니다. 자산, 민심, 시장 열기, 정부 규제라는 4가지 지표를 균형 있게 관리하며 최대한 오래 살아남아야 합니다.

### 주요 기능
- **풍자적 요소**: '강놈', '마푸', '서추' 등 실제 지역명을 비튼 장소들과 '영끌', '갭투자', '초품아' 등 현실적인 키워드 반영.
- **Gemini AI 기반 동적 이벤트**: 정해진 카드 외에도 Google Gemini API를 통해 현재 게임 상황에 맞는 풍자적인 상황이 실시간으로 생성됩니다.
- **Biting Satire**: 시장 참여자들의 탐욕과 고충을 담은 날카로운 피드백.

## 🛠️ 기술 스택
- **Frontend**: React, TypeScript, Tailwind CSS
- **AI**: Google Gemini API (@google/genai)
- **Icons**: Lucide React

## 🚀 시작하기
1. 이 저장소를 클론합니다.
2. `process.env.API_KEY`에 Gemini API 키가 설정되어 있어야 합니다.
3. `index.html`을 브라우저에서 열거나, 개발 서버를 실행하여 플레이합니다.
